# Commons

Commons is a governed platform for connecting data, tools, knowledge,
workflows, and people to agentic software.

Our public repositories include portable SDKs, protocols, providers, examples,
and the [Commons](https://github.com/grasp-labs/commons) learning and agent
distribution.

## Engineering principles

- contracts before coupling;
- deterministic tests before model judgement;
- least privilege and explicit approval for writes;
- evidence, provenance, and human accountability;
- small, reviewable changes.

Start with [Commons](https://github.com/grasp-labs/commons). Security concerns
must be reported privately as described in our
[security policy](https://github.com/grasp-labs/.github/blob/main/SECURITY.md).
